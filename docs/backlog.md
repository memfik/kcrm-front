## Общее — при подключении API

- **Хранилище записей** (`src/lib/list/store.ts`) — в памяти вкладки: создание, правка, удаление, «Передать», «Расторгнуть», решения сбрасываются при перезагрузке. Станет кешем над API.
- **Демо-данные** — `src/data/*.json` (копия базы kCRM 2016–2018) и заглушки имён, БИН, реквизитов в `src/lib/demo-names.ts`. Заменить на API.
- **Опорный месяц** периодов — фиксированный `2018-03` (`src/lib/period.ts`), у сделок `2017-08`. С API — текущий месяц.
- **Текущий пользователь** — заглушка «Администратор» (`src/lib/current-user.ts`); вкладка «Мои» у контрагентов — владелец первой записи (`ME` в `config/lists/counterparties.tsx`). Брать из сессии AD/SSO.
- **Вход** (`/login`) — без авторизации, ведёт на главную. Нужно AD/SSO (§7: пароли не логировать). «Выйти» — просто ссылка на `/login`, без завершения сеанса.
- **Форма записи**: комментарий и вложения не сохраняются; загрузки файлов нет.
- **Формы** — панель без смены адреса: ссылкой на открытую форму не поделиться, после перезагрузки она закрыта (решили так; см. CLAUDE.md). Предзаполнение из другого раздела (`?cs=`, `?deal=`, `?kp=`, `?lead=`) не передаётся.
- **Контрагент в формах** (сделка, КП, запрос скидки, лид) вводится по ID — нужен выбор с поиском по API (2,5 тыс. записей в выпадающем списке неудобны).
- **«Передать»** — список из 14 сотрудников копии базы; нужен справочник сотрудников и права.
- **Выгрузка** — CSV (открывается в Excel), не `.xlsx`.
- **Импорт из файла** — только тост; нужен разбор и проверка строк на сервере.
- **Печать / PDF** — только тост; в макете есть превью документа.
- **История / таймлайны в карточках** — статичные события; брать из журнала действий.
- **Поиск ⌘K** — только разделы и быстрые действия; поиск по контрагентам, БИН и ID — через API.
- **Кнопки шапки списка без действия** (например «Делегировать» у заявок ТВ/ТР) показывают тост «после подключения API».
- **Шапка**: уведомления, счётчики в мега-меню, «Мои задачи: 4», бейдж «4» у «Задач» на телефоне — заглушки.
